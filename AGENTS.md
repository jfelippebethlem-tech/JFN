# GitNexus — Code Intelligence

As regras do GitNexus para este projeto vivem em **`CLAUDE.md`** (seção final), em versão condensada.

**Por que não estão aqui.** `AGENTS.md` e `CLAUDE.md` são AMBOS carregados a cada turno. Este arquivo
era uma cópia literal da mesma seção — ~640 tokens pagos **duas vezes por sessão**, todas as sessões.
Uma fonte, um custo.

⚠️ **Se `npx gitnexus analyze` reescrever este arquivo com o bloco completo de volta**, a duplicação
retorna calada. Sintoma: `AGENTS.md` passar de ~500 bytes. Cura: reduzir a este ponteiro de novo.
